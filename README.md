# The Scarlet Archive

A pale, impossible world containing Tendai Moross Sakadza's software and data engineering portfolio.

## Run locally

Serve the `dist` directory with any static HTTP server, for example `python -m http.server 4173`, then open `http://localhost:4173`.

No build or package installation is needed. `dist/index.html`, `dist/style.css`, and `dist/app.js` contain the site. The assets directory contains the tree artwork and both original CV PDFs.

## Experience

- Three world markers reveal the work, the keeper, and correspondence.
- Seven CV-sourced projects can be filtered by data or software engineering. Expand each artifact for implementation details and supplied links.
- The keeper includes experience, education, GitHub, LinkedIn, and both downloadable CVs.
- Correspondence opens a mailto draft in the visitor's email application. The site does not send or store messages.
- A wandering leaf reveals small secrets. Canvas leaves drift upward into particles.
- Sound is an optional, locally synthesized ambient bed. Stillness stops motion and is remembered in this browser. The initial setting respects reduced-motion preferences.
- The central tree uses generated cinematic artwork animated with CSS and canvas particles; it is not a rotatable WebGL model.

All portfolio facts and external links were transcribed from the two supplied CVs. Descriptive artifact names and world copy were written for this experience. No external project results were independently verified. No analytics or backend services are included. Fonts load from Google Fonts with local serif/sans fallbacks.

Ridiculously dramatic vivid scarlet subject surrounded by almost nothing. High fidelity 3D fine art render, quiet and slightly uncanny, not cartoon.
